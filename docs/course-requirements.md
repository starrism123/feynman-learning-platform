# 16 课要求对照表

按 `要求文档/` 里每课的「课程目标」和「课后作业」整理，右边一栏是本项目的完成情况。第 7 课另有一份 7.5 课（进阶），第 8 课有三个版本（内容相同，按完整版算）。

图例：✓ 做了；↻ 做了，但换了实现方式（原因见 [project-summary.md](project-summary.md)「和讲义的不同」）；✗ 没做（选做题，按取舍标准放弃）。

## 总目标

做一个「费曼学习平台」：用户写知识点笔记 → 录音复述 → AI 转写、润色、打分、出题 → 笔记建成私有知识库，可以问答 → 画成 2D 图谱和 3D 宇宙 → 打包成桌面程序和 PWA → 最后做项目汇报。64 学时，从后端写到前端、AI、可视化、跨平台。

## 第 16 课的复盘问题（老师很可能问）

讲义里让学生讨论的四个问题，回答素材见 [project-summary.md](project-summary.md)「遇到的工程问题和解法」：

1. 开发中遇到的最大技术挑战是什么？怎么解决的？
2. 哪个模块最有成就感？为什么？
3. 如果重来，哪部分会换一种设计或技术选型？
4. 对「全栈开发」「大前端」有了什么新理解？
