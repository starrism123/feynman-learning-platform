# 期末汇报演示流程（第 16 课）

讲义要求：每人 8–10 分钟，5 分钟演示 2–3 个亮点功能，3–5 分钟讲技术亮点、心得和问答。下面是按这个时长排的流程和演示前检查清单。「心得」部分由汇报人自己写，这里只留位置。

目前定的是只交报告、不录视频（2026-10-29）。如果之后要求现场汇报，按下面的流程准备。

## 演示前检查（提前 30 分钟）

各开一个终端（命令详见 README「完整运行」）：

```powershell
npm run db:local                                      # MongoDB
npm run dev                                           # 后端 :3000
cd feynman-platform-frontend; npm run dev             # 前端 :5173
cd whisper-service; .\.venv\Scripts\python app.py     # 语音识别 + 向量化 :5001
```

- [ ] `npm run seed:demo`：重置演示账号和 8 个知识点，并建好向量索引（会让之前的登录失效，跑完重新登录）。
- [ ] `npm run rag:check`：向量服务正常，三组对照全部通过。
- [ ] 在 AI 助手页问一个演示问题，确认 DeepSeek 有响应（没网或没余额时会自动换本地 Ollama，但更慢；确认 `ollama serve` 在跑）。
- [ ] 麦克风权限已允许（复述录音用），准备好要读的一段话。
- [ ] 浏览器缩放 125%、关掉无关标签页和通知；桌面版安装程序在 `feynman-platform-frontend/release/`。
- [ ] 备份视频（如果准备了）放在桌面，现场出问题直接切。

## 技术亮点素材（挑 2–3 条讲）

完整版见 [project-summary.md](project-summary.md) 的「遇到的工程问题和解法」。

1. **AI 组件要能量化验收**：向量模型第一次选的能返回结果，但相关、无关句子分数分不开。写了体检脚本，换成本机 bge 模型后差距都在 0.2 以上。
2. **参数靠评测定**：28 道题的检索评测决定了门槛和块长；试过一种「更高级」的混合检索，数据变差就撤了。
3. **流式输出的坑**：EventSource 不能带登录凭证，用 fetch 读流；中文被切在两个包之间要拼接；已经开始输出就不能换备用模型。
4. **相似度连线**：笔记两两相似度全挤在 0.46–0.69，阈值没法定，改成「互为最近的前 2 名」。
5. **桌面版白屏**：`file://` 下资源路径和路由都要改，同一份代码按构建模式切换。

## 常见问题怎么答

| 可能被问                               | 回答要点                                                                                                          |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 为什么不用讲义的百度接口？             | 本地 Whisper 和本机向量模型免费、断网能用；向量模型是对比测试后选的，有体检脚本                                   |
| 向量为什么存 MongoDB，不用向量数据库？ | 数据量小（几百块），逐个计算约 50 毫秒；和知识点同库，更新删除时一起处理，不留旧向量。上万块时再换 Atlas 向量索引 |
| 讲义说的 MCP 是什么？                  | 讲义指结构化提示词模板；业界的 MCP 是 Model Context Protocol，让 AI 应用连接外部工具和数据的协议，两者不是一回事  |
| AI 会不会胡编？                        | 问答只给检索到的笔记，要求按编号引用；检索不到直接返回「没有相关笔记」，不调用大模型                              |
| 离线能用吗？                           | PWA 断网能打开页面，但数据和 AI 要连后端；桌面版也需要后端开着                                                    |
| 部署了吗？                             | 按课程要求只讲理论；后端和数据库已经容器化，本机 `docker compose` 能跑，上线还差的部分写在 deployment.md          |
| 测试怎么做的？                         | 48 个自动测试，用内存数据库，不调用真实大模型和语音服务（用替身模拟）；另有检索评测脚本                           |

## 现场出问题怎么办

| 现象                                     | 处理                                                                          |
| ---------------------------------------- | ----------------------------------------------------------------------------- |
| AI 点评或问答一直转圈                    | DeepSeek 网络问题，等它自动换 Ollama（慢 10–20 秒）；还不行就切备份视频讲这段 |
| 录音转写失败                             | whisper-service 没开或麦克风没授权；直接在文字框里改一段文字继续点评          |
| 知识库状态显示「N 个需要重建」或检索不到 | AI 助手页点「重建索引」                                                       |
| 页面跳回登录                             | 重新跑过 `seed:demo` 后旧登录失效，重新登录                                   |
