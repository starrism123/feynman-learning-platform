# 项目总结（第 16 课）

费曼学习平台：用「讲给别人听」的方式学技术。用户写知识点笔记，录音复述，AI 教练转写、点评、出题；笔记建成私有知识库，可以问答，也能画成 2D 图谱和 3D 宇宙；网页版能装成 PWA，也能打包成 Windows 桌面程序。

本文是第 16 课「回顾与沉淀」的材料：实际架构、每一阶段做了什么、和讲义的不同及原因、遇到的工程问题。汇报流程见 [final-demo.md](final-demo.md)，部署见 [deployment.md](deployment.md)。

## 实际架构

讲义第 16 课的架构图里有百度智能云、向量数据库、G6、CesiumJS，本项目实际用的是下面这套（差异和原因见后文）。

```mermaid
graph TD
    subgraph 用户端
        A[浏览器 / PWA<br/>可安装、可离线打开]
        B[桌面程序 Electron<br/>file:// + HashRouter]
    end

    subgraph 前端 Vite + React 19
        D[页面：知识点、复述、测评、AI 助手]
        E[登录状态 Context]
        F[路由 React Router]
        G[请求 Axios / fetch 流式]
        H[可视化：ECharts 图谱、Three.js + d3-force-3d 宇宙]
    end

    subgraph 后端 Node.js + Express
        I[REST 接口 /api/*]
        J[JWT 认证中间件]
        L[控制器 → 服务层]
        K[Mongoose 模型]
    end

    subgraph 数据
        M[(MongoDB<br/>用户、知识点、知识块和向量)]
    end

    subgraph 本机 AI 服务 whisper-service（Flask）
        P[Whisper small 语音识别]
        Q[bge-base-zh-v1.5 向量化]
    end

    subgraph 大模型
        R[DeepSeek（主）]
        S[本地 Ollama qwen2.5:7b（备用）]
    end

    A & B -->|HTTP| G
    G --> I
    I --> J --> L
    L --> K --> M
    L -->|转写 / 向量化| P & Q
    L -->|点评、出题、问答| R
    R -.失败时.-> S
```

后端分层：`route → controller → service → model`，`src/app.js` 只组装应用，`src/server.js` 负责连数据库和监听端口，测试直接用 `createApp()`，不起真实端口。

| 接口前缀                | 内容                                     | 课    |
| ----------------------- | ---------------------------------------- | ----- |
| `/api/users`            | 注册、登录、当前用户                     | 2–3   |
| `/api/knowledge-points` | 知识点增删改查，按当前用户隔离           | 3     |
| `/api/audio`            | 上传录音 → Whisper 转写                  | 7–7.5 |

## 和讲义的不同，以及为什么

| 讲义                                    | 本项目                                                 | 原因                                                                                                                                                                    |
| --------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 百度语音识别                            | 本地 Whisper（7.5 课）                                 | 不用申请密钥、不按次计费，断网也能演示                                                                                                                                  |
| 百度千帆向量化                          | 本机 bge-base-zh-v1.5（和 Whisper 同一个 Python 服务） | 先试过 Ollama 里的 bge-m3、Qwen3-Embedding，中文相似度失常（无关句子比相关句子分数还高）；换成 transformers 直接加载后，`npm run rag:check` 三组对照的差距都在 0.2 以上 |
| HNSWLib 存本地文件                      | 向量存 MongoDB 的 `knowledgechunks`                    | 知识点更新、删除时向量跟着整组替换或删除，不会留下旧向量；几百块的数据量逐个算相似度约 50 毫秒，够用                                                                    |
| LangChain LCEL 串链                     | 每一步是普通函数，按顺序调用                           | 步骤少，普通函数更好读、好测                                                                                                                                            |
| 第 11、16 课把结构化提示词叫 MCP        | 叫「结构化提示词」                                     | 业界的 MCP 是 Model Context Protocol（让 AI 应用接外部工具和数据的开放协议），不是提示词格式                                                                            |
| 第 12 课 G6                             | ECharts                                                | 讲义正文用 ECharts，只有结尾的美化部分写 G6，按正文做                                                                                                                   |
| 第 14 课 CesiumJS 数字地球              | Three.js + d3-force-3d 知识宇宙                        | 讲义文件名写 CesiumJS，正文是 Three.js 力导向，按正文做                                                                                                                 |
| 第 15 课 `serve` 用 3000 端口测 PWA     | `npm run preview`（4173）                              | 3000 是后端端口，会冲突                                                                                                                                                 |
| 第 15 课手机用 `http://电脑IP` 安装 PWA | 只做电脑 Chrome 安装 + 离线                            | Service Worker 只能在 HTTPS 或 localhost 下注册，局域网 http 装不了                                                                                                     |

## 遇到的工程问题和解法

挑几个汇报时值得讲的，每个都有数据或测试兜底：

1. **向量模型「看起来能用」但其实不准**（第 10 课）。Ollama 版的向量模型能返回向量，但相关句子和无关句子分数分不开。做了 `npm run rag:check` 体检脚本（三组相关/无关句子，要求差距 ≥ 0.1），换模型后先跑它。教训：AI 组件要有可量化的验收，不能只看「有返回」。
2. **检索参数靠评测定，不靠感觉**（第 10–11 课）。门槛 0.3、块长 300、取 4 块都来自 `npm run rag:eval` 的对比数据。第一版「混合检索（RRF）」反而让命中率下降（首位命中 86%→75%），撤掉；改成「标题点名保底」，综合题覆盖从 9/11 提到 11/11，单题指标不变。
3. **并发写向量的竞态**（第 10 课复查）。同一个知识点连续保存两次，两次建索引交错执行会留下混合的块。每个知识点一条队列串行执行，建索引时从数据库重读最新内容，先插新块再删旧块，删除也排进队列。有并发测试覆盖。
4. **流式输出的细节**（第 11 课）。浏览器的 EventSource 不能发 POST、不能带认证头，所以前端用 `fetch` 读流；中文字符可能被切在两个数据包之间，用流式 `TextDecoder` 拼接；大模型只在吐出第一个字之前允许切换到备用模型，否则用户会看到两段拼起来的回答；用户点停止或关页面时中止上游请求，不浪费 token。
5. **相似度全挤在一起，阈值连线失效**（第 12 课）。8 个技术笔记两两相似度都在 0.46–0.69，定任何阈值都不合适；改成「互为前 2 近邻」才连线，只看排名。
6. **React 开发模式和 Three.js**（第 13 课）。`useEffect` 会执行两次，不清理就叠两层画布、显存一直涨；卸载时停动画循环、释放几何体材质、移除画布。鼠标拾取要按画布自己的位置换算坐标。
7. **力导向把孤立节点推出画面**（第 14 课，桌面版截图时发现）。中心力只平移整体，加了向原点的弱引力。
8. **桌面版白屏**（第 15 课）。`file://` 下绝对路径资源 404、子路由没有服务器兜底；改相对路径和 HashRouter，用同一份代码按构建模式切换。打包工具要建符号链接、没开开发者模式会失败，跳过签名绕开。

## 已知限制

完整清单在 [usage-and-design.md](usage-and-design.md) 的「已知限制」。汇报时可能被问到的几条：问答是单轮的、不记上下文；向量检索全量计算，上万块要换近似索引；建索引的队列只在单进程内有效；PWA 离线时只有页面外壳，数据要连后端；桌面安装程序未签名。
