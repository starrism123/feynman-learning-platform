## 二、演示流程

### 0. 开场（30 秒）｜停在首页

> 这是「费曼学习平台」。费曼学习法的核心是：把一个概念讲给外行听，讲不清的地方就是没懂的地方。平台做的是这件事：我写知识点笔记，然后开口复述，AI 当教练帮我转文字、打分、出题；所有笔记还会建成我自己的知识库，可以提问，也可以画成 2D 图谱和 3D 宇宙。
>
> 整体是前后端分离：前端 React，后端 Node.js + Express，数据库 MongoDB；另外有一个本机跑的 Python 服务，负责语音识别和文本向量化；大模型用 DeepSeek，本地 Ollama 做备用。

### 1. 登录和知识点（1 分钟）｜首页 → 点开一个知识点

**操作**：首页指一下知识点卡片和状态标签（学习中 / 已掌握 / 未开始），在搜索框搜「JWT」，点开「JWT 登录认证」详情。

> 登录用的是 JWT：密码用 bcrypt 加盐哈希后存库，登录成功后服务器签发一个 token，之后每个请求都带上它，后端中间件验证签名就知道是谁。每个用户只能看到、改到自己的知识点，后端查询时都按当前用户过滤。
>
> 笔记用 Markdown 写，支持表格、数学公式（KaTeX）和流程图（Mermaid）。渲染时不执行笔记里的原始 HTML，防止笔记里藏脚本搞 XSS 攻击。

**用了什么**：Express 路由、控制器、模型分层；Mongoose；bcrypt；JWT；React Router；react-markdown + KaTeX + Mermaid。

### 2. ★ 复述闭环（2 分钟）｜详情页点「开始复述」

**操作**：

1. 点「开始录音」，用自己的话讲 15–20 秒 JWT 是什么，点停止。
2. 等「语音识别结果」出来（约 4 秒），指一下文字。
3. 点「请 AI 教练点评」，等约 3 秒，指一下：润色后的文本、四个维度的分数、综合得分、优点、待改进。
4. 回到详情页点「开始测评」，选「单选题 / 基础」，AI 现场出一道题，选一个答案提交，看判分和解析。

> 录音用的是浏览器的 MediaRecorder，录完上传到后端。语音识别我没用讲义的百度接口，换成了在本机跑的 Whisper 模型：不用申请密钥，不按次收费，断网也能识别。
>
> 转出来的文字交给大模型，按「准确性、清晰度、完整性、简洁性」四个维度打分，还给出润色后的版本和改进建议。低于 60 分会自动进入「待复习」。
>
> 测评页是 AI 根据这条笔记现场出题，可以选题型和难度，提交后再由 AI 判分讲解。

**用了什么**：MediaRecorder、multer 文件上传、Python Flask + Whisper small、DeepSeek（走 OpenAI 兼容接口，失败时自动换本地 Ollama）、结构化提示词让大模型返回固定格式的 JSON。

### 3. ★ AI 助手：知识库问答（2 分钟）｜导航栏「AI 助手」

**操作**：

1. 指一下顶部：「知识库：8 个知识点 · 15 块 · 向量服务在线」。
2. 问「useEffect 的依赖数组有什么用」，回答一个字一个字流出来；指一下句末的 [1][2]，展开下面的「引用来源」。
3. 再问「红烧肉怎么做」，它直接回答知识库里没有相关笔记。

> 这是 RAG，检索增强生成。我的每条笔记会被切成小段，每段用本机的 bge 中文模型转成 768 维的向量存进 MongoDB。提问时，先把问题也转成向量，找出最相近的几段笔记，再把这几段交给大模型，让它只根据这些内容回答，并标出处。
>
> 所以它的回答是有来源可查的。第二个问题和笔记无关，检索不到就直接拒答，根本不调用大模型，不会瞎编。
>
> 回答是流式输出的，大模型生成一点前端就显示一点。

**用了什么**：文本切分、bge-base-zh-v1.5 向量化、余弦相似度检索、相关度门槛 0.3、SSE 流式输出（前端用 fetch 读流）。

**可以加一句（工程亮点）**：

> 向量模型一开始用的是 Ollama 里的模型，能返回结果，但实测发现无关句子的相似度反而比相关句子高。我写了一个体检脚本对比，换成现在这个模型后，相关和无关的差距都在 0.2 以上。检索门槛、每段多长、取几段，也都是跑 28 道评测题定下来的，不是拍脑袋。

### 4. 知识图谱（1 分钟）｜导航栏「知识图谱」

**操作**：等节点散开、稳定下来，滚轮缩放，拖一个节点，鼠标悬停在一条蓝色虚线上看相似度，最后点一个节点跳到知识点详情。

> 这是用 ECharts 力导向布局画的知识图谱。黑色实线箭头表示一条笔记的正文里提到了另一条的标题；蓝色虚线表示两条笔记内容相似。
>
> 虚线不是我手动连的，是用前面那套向量算出来的：两条笔记互相排在对方最相似的前 2 名里才连线，线越粗越相似。一开始我试过定一个相似度门槛，但 8 条技术笔记的相似度都挤在 0.46 到 0.69 之间，门槛怎么定都不合适，所以改成按排名连线。

**用了什么**：ECharts graph 力导向布局、后端 `/api/graph/knowledge-map` 计算两种边。

### 5. ★ 3D 视界和知识宇宙（1.5–2 分钟）｜导航栏「3D 视界」→「知识宇宙」

**操作**：

1. 「3D 视界」：先点右上角「入门：旋转立方体」，展示最基础的 3D 场景；再切回「随机星图」，左键拖动旋转，滚轮缩放，鼠标移到一个星球上，它和相连的航线会高亮。
2. 「知识宇宙」：拖动旋转看整体，点一个星球选中它，相邻的星球和连线高亮，点空白处取消。

> 3D 部分用的是 Three.js。最基本的三要素是场景、相机、渲染器，旋转立方体就是这三样加一个每帧转一点的动画循环。
>
> 星图里每个星球是一个知识点，鼠标悬停高亮用的是射线拾取：从相机穿过鼠标位置发一条射线，看它先碰到哪个球。
>
> 知识宇宙的星球位置不是随机的，是用 d3-force-3d 力导向算法算出来的：有连线的知识点互相吸引，没关系的互相排斥，所以相关的知识会自然聚成一团。我还加了一个向中心的弱引力，不然孤立的知识点会被推出画面。
>
> 2D 图谱和 3D 宇宙用的是同一份连线数据，展示方式不同。

**用了什么**：Three.js（场景、透视相机、WebGL 渲染器、OrbitControls、Raycaster）、d3-force-3d、React `useEffect` 里创建和清理场景。

**可以加一句（工程亮点）**：

> React 开发模式下 useEffect 会执行两次。一开始没写清理，页面上叠了两层画布，显存一直涨；后来在卸载时停掉动画循环、释放几何体和材质、移除画布才解决。

### 6. 跨平台（30 秒，可选）

> 同一份前端代码还做了两种形态：用 Electron 打包成 Windows 桌面安装程序；网页版加了 PWA，可以在 Chrome 里「安装」，断网后页面外壳还能打开。桌面版碰到过白屏，原因是本地文件路径下绝对路径和前端路由都不能用，改成相对路径和 Hash 路由解决的。

注意：`feynman-platform-frontend/release/` 里的安装包是 10-29 打的，那时知识图谱页有一个空白的 bug（11-19 才修好，见第四节）。如果要现场演示桌面版，只展示首页和 3D 页面，或者先重新打包。

### 7. 收尾（30 秒）

> 总结一下：后端是 Express + MongoDB，有 48 个自动测试；AI 部分是本机 Whisper 和向量模型加 DeepSeek；可视化有 ECharts 图谱和 Three.js 3D。和讲义不一样的地方，比如不用百度接口、向量存 MongoDB，都是对比测试之后定的，原因写在项目总结文档里。

## 三、老师可能会问

### 原理类

| 问题                               | 回答要点                                                                                                                                                                     |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JWT 怎么工作的？存在哪？           | 三段：头部、载荷、签名。载荷只是 Base64 编码，不是加密，所以不能放密码。服务器用密钥签名，篡改后签名对不上。前端存在 localStorage，每次请求放在 `Authorization: Bearer` 头里 |
| 为什么密码要哈希、不能加密？       | 加密能解回原文，哈希不能。bcrypt 自带随机盐，相同密码存出来也不一样，防彩虹表；而且故意算得慢，防暴力破解                                                                    |
| RAG 是什么？为什么不直接问大模型？ | 先检索、再生成。大模型不知道我的私人笔记，直接问会按通用知识回答甚至编造；先检索出相关笔记再让它照着答，回答有出处、可核对                                                   |
| 向量、相似度是什么意思？           | 把一段文字转成一串数字（这里 768 个），意思相近的文字，向量方向也相近。用余弦相似度衡量，越接近 1 越相似                                                                     |
| 流式输出怎么实现的？               | 后端用 SSE，大模型每生成一小段就推给前端。浏览器自带的 EventSource 不能带登录凭证，所以前端用 fetch 读流，并处理中文被切在两个数据包之间的问题                               |
| 力导向布局是什么？                 | 把节点当成带电粒子、连线当成弹簧：节点之间互相排斥，有连线的被弹簧拉近，反复迭代到平衡，相关的节点自然聚在一起                                                               |
| Three.js 的基本结构？              | 场景（放东西）、相机（从哪看）、渲染器（画到 canvas 上），再加一个 requestAnimationFrame 动画循环每帧重画                                                                    |
| React 的 useEffect 是干嘛的？      | 处理副作用：请求接口、定时器、操作 DOM。依赖数组决定什么时候重新执行，返回的函数负责清理                                                                                     |

### 选型类

| 问题                                            | 回答要点                                                                                                                                 |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 为什么不用讲义的百度接口？                      | 本地 Whisper 和本地向量模型不要密钥、不按次收费、断网能用；向量模型是对比测试后选的，有体检脚本                                          |
| 向量为什么存 MongoDB，不用向量数据库？          | 数据量小（几百段），全部算一遍约 50 毫秒；和知识点放在同一个库，修改、删除笔记时向量一起更新，不会留下旧数据。上万段时再换专门的向量索引 |
| 讲义里第 14 课写的是 CesiumJS，你怎么没做地球？ | 讲义文件名写的 CesiumJS，但正文内容是 Three.js 力导向 3D 知识宇宙，我按正文做的                                                          |
| DeepSeek 挂了怎么办？                           | 统一走 OpenAI 兼容接口，DeepSeek 出错时自动换本地 Ollama 的 qwen2.5:7b。流式回答一旦开始输出就不再切换，避免两段回答拼在一起             |
| 部署了吗？                                      | 按课程要求讲了部署理论，没有上云服务器。后端和数据库已经写了 Docker 配置，本机能一条命令启动，上线还差什么写在 `docs/deployment.md`      |
| 怎么保证代码没问题？                            | 后端 48 个自动测试，用内存数据库，不调用真实的大模型和语音服务（用替身模拟）；检索效果有 28 道评测题的脚本                               |

## 四、现场出问题怎么办

| 现象                              | 处理                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| 点评或问答一直转圈                | DeepSeek 网络问题，等它自动换 Ollama（慢 10–20 秒）；还不行就说明原因，跳到 3D 部分 |
| 录音后没有文字                    | Python 服务没开或麦克风没授权；直接在识别结果文本框里打一段字，继续点评             |
| AI 助手显示「需要重建」或检索不到 | 点「重建索引」                                                                      |
| 页面跳回登录                      | 跑过 `seed:demo` 后旧登录失效，重新登录                                             |
| 知识图谱空白                      | 11-19 已修（原因：图表初始化时容器宽度是 0）。万一再出现，刷新一次页面              |
